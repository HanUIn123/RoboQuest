# RoboQuest 개인 프로젝트 (DirectX11 기반 FPS 게임)

## ■ 개요
- RoboQuest는 FPS 기반 보스전 중심 슈팅 게임입니다.
- **C++ / DirectX11 / HLSL / ImGui / Windows API 기반으로 자체 엔진을 사용하여 제작한 개인 프로젝트입니다.**

## ■ 개발 환경
- 언어: C++, HLSL
- 개발 도구: Visual Studio, Windows API, DirectX11, ImGui, Fmod

## ■ 주요 구현 기능

### 1. FPS 조작 시스템
- **RayCast**를 활용한 정밀 슈팅 구현
- 슬롯 기반 **무기 스왑 시스템**
- **스나이퍼 모드 줌인** 처리 (마우스 우클릭 → 크로스헤어 전환)
- 플레이어 **슈팅 시 총알 트레일 이펙트** 출력
- 피격 대상에게 **경고 텍스트 출력 및 반응 연출**

### 2. 플레이어 컨트롤
- 기본 조작: **WASD 이동**, **대쉬**, **점프**, **슈팅**, **장전**
- **장전 시 탄약 UI**와 연동되어 실시간 표시
- 모든 상태 동작은 **FSM 기반 상태 전이**로 구성

### 3. 몬스터 AI
- **Navigation 기반 경로 이동 및 경로 추적**
- **감지, 추적, 공격, 사망** 상태 흐름으로 구성
- 공격 시 대미지 판정 및 **넉백/경직 애니메이션 출력**
- 사망 시 **디졸브 셰이더**, **파편 효과**, **사운드** 재생

### 4. 보스 AI
- **보스 등장의 연출** 및 고유 UI 패널 연동
- 총 **4가지 패턴 공격**을 FSM으로 구현:
  1. 직선 미사일 연사
  2. 랜덤 좌표 지정 미사일 공격
  3. 전기 트랩 지대 생성
  4. 장벽 소환 및 진입 차단

### 5. UI 연출
- **체력 UI**, **탄약 UI**, **피격 방향 화살표**, **붉은 틴트 효과** 등 HUD 구성
- 플레이어 및 몬스터 체력 수치 실시간 반영
- 스킬 및 특수 연출 시 UI 효과 동기화

### 6. 이펙트 처리
- **총알 이펙트**: 탄흔, 파편, 사운드 연동
- **피격 이펙트**: 전기 이펙트 + 붉은 화면 연출
- **보스 패턴 이펙트**: 전기지대, 미사일 폭발, 진입 차단 장벽 등 각각 분리 처리
- 몬스터 사망 시 **디졸브 + 쉐이더 + 음향** 결합 연출

## ■ 구현 파트 핵심 요약
- FPS 조작 시스템 (RayCast 기반 슈팅, 무기 전환, 스나이핑 줌)
- 플레이어 FSM 입력 처리 및 상태별 전이 구현
- 몬스터 AI: 상태 전이, 경로 추적, 피격/사망 연출
- 보스 AI: 패턴 기반 공격 FSM + 고유 연출
- 실시간 전투 HUD UI 구성 (체력, 탄약, 피격 방향)
- 총기/보스/사망에 따른 상황별 FX 연출
